# Resume PDF Setup

Apna resume PDF yahan place karo:

**Path:** `public/resume.pdf`

## Steps:
1. Apna resume kisi bhi tool se PDF mein export karo:
   - [Canva](https://canva.com) — professional resume templates
   - [Resume.io](https://resume.io)
   - Microsoft Word → Export as PDF
   
2. File ka naam exactly `resume.pdf` rakho

3. Is file (`RESUME_INSTRUCTIONS.md`) ko delete kar sakte ho
